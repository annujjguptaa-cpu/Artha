# Artha — 3-Minute Live Demo Script

**Objective**: Demonstrate multi-platform grocery price comparison, split-cart savings optimization, and 1-click Chrome Extension cart execution across **Zepto**, **Blinkit**, and **Swiggy Instamart**.

---

## 🎬 Act 1: The Problem & List Input (0:00 - 0:45)

1. **Open Artha Web Frontend** (`http://localhost:3000` or deployed Vercel URL).
2. **Narration**: *"Grocery delivery platforms like Zepto, Blinkit, and Swiggy Instamart have wildly varying prices and item availability. Manually checking each app takes 15+ minutes every week. Artha solves this with AI agent scraping and deterministic split-cart optimization."*
3. **Click "Paste from Clipboard"** or select the **"Breakfast Staples"** quick preset button.
4. Point out the parsed item count badge (`5 items detected`).
5. **Click "Compare Prices Across All Platforms"**.

---

## 📊 Act 2: Live Agent Scraping & Optimization (0:45 - 1:45)

1. Show the **Live Progress Bar** ("Checking 5/5 items across Zepto, Blinkit, Instamart...").
2. When the results land:
   - Highlight the **Giant Savings Banner** (*"You Save ₹245 with Split-Cart Optimization"*).
   - Show the **Price Comparison Breakdown**:
     - Artha Split Cart: `₹380`
     - Zepto Single Cart: `₹465` (+₹85)
     - Blinkit Single Cart: `₹440` (+₹60)
     - Instamart Single Cart: `₹510` (+₹130)
3. Scroll through the **Platform Grouped Items**:
   - Point out **Needs Review** item (amber border for brand-lock / price variance confirmation).
   - Click **"Change Match"** on an item to demonstrate manual product/platform override.

---

## 🛒 Act 3: Automated Extension Cart Building (1:45 - 2:45)

1. **Click "Build My Carts"** primary action button.
2. Show the **Artha Chrome Extension Popup**:
   - Point out the active status pill (`Running: Adding to Zepto...`).
   - Show live item execution progress bar (`3/5 completed`).
   - Scroll through real-time execution logs (`Added "Amul Milk 1L" to Zepto cart`).
3. Switch to active platform web tab (**Zepto / Blinkit**) and point out the incremented cart badge icon.

---

## 📈 Act 4: Cumulative History & Wrap-Up (2:45 - 3:00)

1. Click **"History"** in top navbar.
2. Highlight the aggregate monthly savings header (*"You've saved ₹1,240 across 4 lists this month"*).
3. **Conclusion**: *"Artha delivers maximum grocery savings with zero manual friction — whether on iOS or Web."*
